# ТЗ: «Твой Прогноз» (Telegram Mini App)

## Кратко
Ежедневный прогноз с двумя блоками: «Судьба» + «Совет дня». Тон нейтральный. История прогнозов бесконечная. Мультиязычность для СНГ + EN + LT.

## Функции
- **1 бесплатный прогноз в день**
- **Платный «Новый прогноз»**: 25 ⭐, лимит 3/день
- **История**: вкладка на главной, сортировка по дате (новые сверху), хранение без лимита
- **Пуш‑напоминание**: 10:00 МСК
- **Профиль**: не нужен

## Экраны/флоу
**Главный экран**
- Заголовок «Твой Прогноз»
- Дата
- Текст прогноза (2–3 предложения, два блока)
- Кнопка: «Новый прогноз (25⭐)»
- Счетчик: «Осталось N/3 сегодня»
- Вкладка «История»

**История**
- Лента прогнозов по дате (новые сверху)
- По одному прогнозу на карточке

**Покупка**
- Telegram Stars purchase
- После оплаты — новый прогноз + обновить лимит

**Пуш (бот)**
- Ежедневно 10:00 МСК: «Прогноз дня доступен»

## Логика
- Хранить лимит по user_id и дате
- История бесконечная

## Языки
- СНГ: RU, UA, KZ, UZ, AZ, BY, KY, AM, GE, TJ, TM, MD
- Дополнительно: EN, LT

## Техстек (минимум)
- WebApp: React/Vite + Telegram WebApp SDK
- Бэкенд: Node.js + PostgreSQL
- Бот: Telegraf/grammY
